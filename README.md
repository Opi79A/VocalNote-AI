# 🎙️ VocalNote-AI

**VocalNote-AI** is a smart voice-to-text logging system designed to capture and transcribe spoken words into digital notes in real-time.

## 🚀 Overview
This project leverages the power of the **Google Speech Recognition API** to provide an efficient way of documenting thoughts, meetings, or reminders without typing. It features automated noise adjustment and persistent storage.

## ✨ Features
* **Live Transcription**: Converts audio to text instantly.
* **Auto-Logging**: Appends every recognized sentence into `output.txt`.
* **Smart Audio Processing**: Uses `adjust_for_ambient_noise` to filter background sounds.
* **UTF-8 Support**: Full support for different languages and special characters.

## 🛠️ Technical Stack
- **Language**: Python
- **APIs**: Google Speech API
- **Libraries**: `SpeechRecognition`, `PyAudio`, `pyttsx3`
